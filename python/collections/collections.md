# Какие бывают коллекции данных в python:
- Список(list)
- Множество(set)
- Кортеж(tuple)
- Словарь(dict)

### Список(list)
Является упорядоченной изменяемой неуникальной коллекцией данных.\
Подходит для хранения данных, где важен порядок.
- Поиск O(N)
- Вставка O(1), в случае если приходится увеличивать размер массива в памяти, то сложность вырастает до O(N). Происходит это из-за того, что объекты в памяти перемещаются в место с большей размерностью

### Множество(set)
Является неупорядоченной изменяемой уникальной коллекцией данных.\
Устроена внутри как хеш-таблица. Также существует frozenset(), является тем же множеством, но неизменяемым. Объектами множества могут являться только хешируемые объекты.

Подходит для хранения уникальных данных, где не важен порядок.

- Поиск O(1)
- Вставка O(1), в случае если приходится увеличивать размер массива в памяти, то сложность вырастает до O(N). Происходит это из-за того, что объекты в памяти перемещаются в место с большей размерностью


### Кортеж(tuple)
Является упорядоченной неизменяемой неуникальной коллекцией данных.\
Подходит для хранения данных, где важно знать о том, что данных объект никогда не будет изменен(Например координаты места).

- Поиск O(N)
- Вставка невозможна, требуется создавать новый кортеж

### Словарь(dict)
Является коллекцией данных работающей как хеш-таблица.\
Ключами словаря могут являться только хешируемые объекты.

- Поиск O(1)
- Вставка O(1), в случае коллизий, сложность может возрасти до O(N). Происходит это из-за того, приходится перезаписывать каждый хеш ключа.
